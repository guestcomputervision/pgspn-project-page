PGSPN: Physics-Guided Spatial Propagation Network
for Sparsity-Robust Underwater Depth Completion

Abstract

Depth completion recovers dense metric depth from sparse measurements, a capability underwater robots need for mapping, navigation, and manipulation. Existing methods assume uniformly distributed sparse depth, but underwater sources such as Structure-from-Motion (SfM) and field-of-view-limited sensors yield spatially biased measurements with frame-varying density, causing severe degradation. Underwater scenes pose a second challenge: expansive open-water regions lack ground-truth supervision. Without such supervision, estimated depths erroneously extend beyond object boundaries into empty space, a phenomenon we term depth bleeding. To address both challenges, we propose PGSPN, a physics-guided depth completion framework that exploits underwater optical attenuation to estimate transmission maps and derive a sparsity-robust metric depth prior. Our Physics-Guided Propagation Suppression (PGPS) module explicitly prevents depth bleeding by attenuating propagation across transmission-derived depth discrepancies. We additionally introduce the Depth Bleeding Index (DBI), a new metric for quantifying boundary preservation in open-water regions. Evaluated on real underwater datasets with sequence-level splits, cross-dataset generalization, and real sensor imagery, PGSPN reduces MAE by up to 53.6% over the best baseline while achieving the lowest DBI across all conditions.

Key Insights

Irregular Sparsity in Underwater Environments

Unlike terrestrial LiDAR which provides uniformly distributed depth, underwater sources (SfM, sonar) produce spatially biased, frame-varying sparse measurements. Large open-water regions lack any depth supervision, causing severe depth bleeding artifacts.

Physics-Guided Metric Prior

We exploit the Beer–Lambert law: underwater light attenuation embeds depth-dependent photometric cues in RGB images. By estimating per-channel transmission maps and rescaling to metric scale, we obtain a dense, boundary-preserving depth prior independent of sparse input density.

Depth Bleeding Suppression

Our PGPS module leverages the transmission-based prior to modulate spatial propagation weights—fully preserving propagation within homogeneous regions while exponentially suppressing it across depth discontinuities at open-water boundaries.

Network Architecture for Transmission Estimation

For Stage 1 transmission estimation, we adapt AdaBins with minimal modifications to predict per-channel transmission maps $\hat{\mathbf{T}}_c$ and ambient backscatter $\hat{\mathbf{B}}_c$. We preserve the entire original architecture—including the encoder-decoder, transformer encoder, patch embeddings, and regressor modules—modifying only two components:

(1) Multi-channel bin regression: We expand the MLP output dimension from $\mathbb{R}^{1 \times \text{bin\_nums}}$ to $\mathbb{R}^{3 \times \text{bin\_nums}}$, enabling independent bin width prediction for each color channel. This captures wavelength-dependent attenuation characteristics while preserving all other operations from AdaBins—bin edge computation, depth score generation via dot-product, and weighted combination for transmission estimation.

(2) Ambient light estimation: We add a single $1 \times 1$ convolutional layer that projects attention map features to 3-channel ambient light estimates $\hat{\mathbf{B}}_c \in \mathbb{R}^{3 \times H \times W}$, enabling photometric reconstruction.

Dataset Details and Experiments Setup

We train and evaluate on FLSea-Stereo and FLSea-VI, which provide real underwater sequences captured at 10 Hz. FLSea-Stereo contains stereo image pairs at 1280×720, while FLSea-VI provides monocular sequences at 968×608, both with corresponding metric depth. All images are resized to 960×576 and evaluated within a depth range of 0–25 m, where underwater optical cues remain informative and typical degradations such as turbidity and caustics are present.

Sparse Depth Configurations

Feature Matching (FM): To evaluate under practical deployment conditions, sparse depth is obtained from stereo feature matching on rock_garden1, which provides calibrated stereo pairs. SIFT keypoints are detected in both views after undistortion, matched with Lowe's ratio test and cross-check verification, and geometrically verified via essential matrix estimation with RANSAC. Inlier correspondences are triangulated and scaled to metric depth using the known stereo baseline, followed by reprojection error filtering, depth range constraints, and MAD-based outlier rejection—so the resulting measurements contain only triangulation-level noise without gross outliers. Unlike the other three configurations, the number of valid points varies substantially across frames depending on scene texture and viewing geometry.

SfM (Structure-from-Motion): To emulate sparse depth from multi-view reconstruction, we run COLMAP on each sequence. For each evaluation frame, the reconstructed 3D points are projected onto the image plane using the corresponding pose and intrinsics to determine the measurement locations, and the corresponding metric depth at these projected locations forms the sparse input; pixels without a valid projection are treated as missing.

Uniform Random Sampling: Given a fixed budget of $N$ samples, pixels are uniformly sampled at random from locations with valid metric depth.

Bias (Height-Constrained Sampling): Models sensors with a restricted field-of-view. Starting from a uniform random mask with $N{=}400$ samples, only points within a central band covering a specified percentage of the image height are retained:

$$\frac{1-r}{2}H \leq y < \frac{1+r}{2}H$$

This produces vertically biased sparse depth that concentrates measurements in the central region while leaving upper and lower areas unobserved.

Train/Test Protocol

We adopt a sequence-level protocol to prevent temporal leakage. Three sequences are reserved entirely for testing (rock_garden1 from FLSea-Stereo, flatiron and cross_pyramid_loop from FLSea-VI), with the remaining 13 sequences as training data: canyon1, canyon2, rock_garden2 from FLSea-Stereo, and horse_canyon, tiny_canyon, u_canyon, big_dice_loop, coral_table_loop, dice_path, landward_path, northeast_path, pier_path, sub_pier from FLSea-VI (~25k training, ~5k test images). The different resolutions and feature distributions across these datasets enable comprehensive evaluation under diverse underwater conditions, from feature-sparse to feature-rich environments. Cross-validation on SeaThru D3 is performed without fine-tuning.

Synthetic Open-Water Generation for DBI

We identify the top 25% of image height as the candidate open-water region, detect the foreground boundary by finding the uppermost row with valid ground-truth depth for each column, then place a rectangular ROI of height $H_{\text{roi}}{=}60$ px immediately above this boundary. Boundary pixel pairs $(p_{\text{in}}, p_{\text{bd}})$ are sampled within a band of width $W_{\text{bd}}{=}5$ px along the foreground edge, with the interior pixel $p_{\text{in}}$ selected as the nearest pixel within the ROI to each boundary pixel $p_{\text{bd}}$. This synthetic setup enables controlled evaluation of bleeding artifacts without requiring ground-truth depth in open-water regions, which is inherently unavailable. The full DBI definition, reliability analysis (correlation with real open-water regions), qualitative examples, and sensitivity studies are provided in the Depth Bleeding Index section below.

Depth Bleeding Index: Qualitative Analysis & Joint Interpretation

The DBI definition, synthetic open-water generation, and reliability analysis against real open-water regions are given in Sec. V-A of the main paper. Here we complement them with representative qualitative examples and discuss how DBI should be read together with the standard pointwise accuracy metrics.

Representative DBI Values

Across the two representative test sequences under SfM 100% input, the DBI values match those reported in the main paper (Table I): PGSPN consistently achieves the lowest DBI (0.211 on rock_garden1, 0.411 on flatiron), indicating well-preserved discontinuities at open-water boundaries, while BP-Net exhibits the highest DBI (0.568, 0.740) with visible bleeding into the synthetic open-water region; DySPN falls in between (0.412, 0.498). The qualitative examples below visualize these differences, confirming that DBI meaningfully captures the severity of bleeding artifacts at open-water boundaries.

Reading DBI Together with Pointwise Accuracy

DBI measures depth discontinuity preservation at open-water boundaries—by design, it does not directly reflect pointwise depth accuracy within the evaluated regions. For instance, a method producing sharp but biased predictions at boundaries may still achieve a favorable DBI score, and DBI does not exclusively isolate bleeding from other discontinuity sources. This is why, in all experiments, we jointly report DBI alongside standard metrics (MAE, RMSE, $\delta_k$) computed over GT-valid regions: the two views are complementary, and bleeding suppression should always be interpreted in the context of overall depth accuracy. A method is only convincing when it scores well on both—as PGSPN does across all sequences and sparsity conditions.

Since open-water regions inherently lack ground-truth depth, directly measuring bleeding against ground truth is impossible; DBI offers a practical alternative using reliable boundary predictions as references. We hope this metric, interpreted jointly with pointwise accuracy, provides a useful baseline for future work on evaluating depth completion in supervision-free regions.

Robustness Analysis

Complementing the limitation analysis in the main paper (Sec. V-E), we qualitatively examine behavior under real sensor noise that could not be covered there.

Robustness to Sparse Depth Noise (Real Sonar)

Our main experiments sample sparse depth from ground truth to isolate sparsity patterns from sensor noise. To qualitatively illustrate behavior under real sensor noise, we evaluate on sonar-RGB imagery where sparse depth comes directly from sonar measurements. No ground truth is available here, so we do not claim a pointwise win: qualitatively, the baselines propagate the banded, noisy sonar measurements into visible depth artifacts, whereas PGSPN produces a spatially coherent map, consistent with the transmission-based prior's structure being driven predominantly by RGB observations and staying largely insensitive to sparse depth noise, which perturbs mainly the metric scale fitted from the sparse anchors. We note the noise level in this dataset is relatively mild: systematic evaluation under severe measurement noise (multi-path reflections, gross triangulation failures) and with diverse real sensor modalities remains future work—our Bias configuration captures the spatial distribution of FoV-limited sensors such as sonar, but not their sensor-specific noise properties.
